# VendaFácil POS

**An offline point-of-sale (POS) application built with Python and Kivy.**

VendaFácil POS is a desktop application designed to simplify sales operations and business management. It provides tools for managing products, recording sales, tracking stock, reviewing transaction history, and monitoring business performance.

The application is designed to work offline, making it useful for businesses that need to manage their daily operations without depending on a continuous internet connection.

## Features

- **Sales management:** record and manage sales transactions.
- **Receipt generation:** issue receipts for recorded sales.
- **Product management:** register and maintain product information.
- **Stock control:** monitor inventory and identify products that require restocking.
- **Sales history:** review previously recorded transactions.
- **Cost management:** record and monitor business expenses.
- **Profit tracking:** analyze sales and profit information.
- **Credit management:** keep track of customer credit transactions.
- **Business dashboard:** view key information about business operations.
- **Configurable settings:** adjust application settings to suit the business.
- **Offline operation:** use the application without requiring a continuous internet connection.

## Language and Development

VendaFácil POS is currently available **only in Portuguese**.

The application is under continuous development, with the goal of making it increasingly useful and adaptable to different types of businesses. Future improvements will focus on expanding its capabilities, refining existing features, and supporting a wider range of business needs.

## Technologies

- **Python** — application logic.
- **Kivy** — graphical user interface.
- **KivyMD** — Material Design components and interface elements.
- **SQLite** — local database for storing business information.
- **ReportLab** — PDF document generation, including reports.

- Desktop application.
